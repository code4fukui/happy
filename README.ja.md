# happy

「鯖江SDGsアプリ『ハピー』」は、福井県鯖江市で国連の持続可能な開発目標（SDGs）を推進するためのFlutterアプリケーションです。地元のイベントに参加したり、協力店舗を利用することでポイントを獲得できます。

## デモ

アプリのメイン画面では、現在のポイント合計を表示し、主要な機能にアクセスできます。

## 機能

- **ポイント管理**: 「ハピー」ポイントとSDGsポイントを記録・確認できます。
- **QRコードスキャン**: イベントや店舗でQRコードをスキャンしてポイントを獲得できます。
- **イベント一覧**: 開催予定のSDGs関連イベントの一覧を閲覧できます。
- **ショップ検索**: 協力している地元店舗をマップで確認できます。

## はじめに

### 必要条件

- Flutter SDK: `_>=2.16.1 <3.0.0_`

### インストールと使用方法

このプロジェクトを実行するには、以下の手順に従ってください。

1. 必要なバージョンのFlutter SDKがインストールされていることを確認します。
2. リポジトリをクローンします:
    ```sh
    git clone https://github.com/your-username/happy.git
    ```
3. プロジェクトのディレクトリに移動します:
    ```sh
    cd happy
    ```
4. 依存関係をインストールします:
    ```sh
    flutter pub get
    ```
5. アプリを実行します:
    ```sh
    flutter run
    ```

## 主な依存関係

このプロジェクトでは、以下の主要なパッケージを使用しています:

- QRコードのスキャン: [flutter_barcode_scanner](https://pub.dev/packages/flutter_barcode_scanner)
- アプリ内の効果音: [audioplayers](https://pub.dev/packages/audioplayers)
